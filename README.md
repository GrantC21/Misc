# App web pages

Support and privacy pages for my apps. One folder per app:

| Folder | App |
|---|---|
| `ace/` | Ace: Volleyball Tracker |
| `asplaybook/` | Automotive Sales Playbook |
| `salestower/` | Sales Tower |

The root `index.html` is just a list linking to each app's pages.
To add a new app, make a new folder with an `index.html` (support) and `privacy.html`, then add it to the root list.
